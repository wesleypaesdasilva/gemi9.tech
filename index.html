O que está no Mapa SMART

Seis blocos que cobrem a stack completa da plataforma moderna, em ordem de aprendizado.

01

IA como ferramenta do engenheiro

Cursor, Claude Code e prompts para infra. Como usar IA para aprender, construir e validar — antes de qualquer outra coisa.

02

Concepção e IaC

Terraform, Cloud vs On-premises e Kubespray. Infraestrutura declarada em código, versionada como software.

03

Orquestração com Kubernetes

Arquitetura do cluster, workloads, CNI (Cilium), Storage (Rook-Ceph, Longhorn), Ingress com Traefik e Service Mesh com Istio.

04

Segurança e Governança

Vault para secrets, Kyverno para policies, RBAC e Network Policies. Menor privilégio como padrão desde o início.

05

Entrega e GitOps

Docker, CI/CD como conceito, ArgoCD e Helm. Git como fonte da verdade — o que está no repo é o que está no cluster.

06

Observabilidade e SRE

Grafana Stack (Prometheus, Loki, Tempo) e os pilares do SRE: SLI, SLO, SLA, Error Budget, Toil e Postmortem.
